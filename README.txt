# Sisira K Portfolio

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling, colors, hover effects, and animations
- `script.js` — mobile navigation, scroll reveal animations, footer year, and back-to-top button
- `cv.pdf` — add your actual CV PDF here for the Download CV button to work

## Run locally
1. Extract this ZIP.
2. Put your CV PDF in this same folder and name it `cv.pdf`.
3. Open `index.html` in a browser. For the best development experience, use VS Code with Live Server.

## Before publishing
- In the Experience section, replace `2–26 · Month/year to confirm` with the actual internship dates/duration. Only “2 to 26” was available, so the month/year was not guessed.
- Check your education details and project descriptions for accuracy.
- Email button opens Gmail's compose page in a new tab. If Gmail asks you to choose an account, select your Gmail account.
- External profile links currently point to the GitHub and LinkedIn URLs provided.

## Deploy
Upload `index.html`, `style.css`, `script.js`, and `cv.pdf` together to your hosting provider. Keep the filenames unchanged unless you also update the links in `index.html`.
